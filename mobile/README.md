# P Nagarjun - Portfolio Mobile App (React Native & Expo)

A native mobile application for **P Nagarjun's Portfolio**, built using **React Native** and **Expo**.

## 📱 App Highlights & Architecture

- **⚡ Overview & Hero Screen**:
  - Live interactive **Developer Terminal** streaming simulated multi-agent logs, with switchable file tabs (`agents.py`, `sam_seg.py`, `spec.json`) and syntax-highlighted snippets.
  - Profile highlights, status badge, key stats (CGPA 8.85, Agentic AI, 97.9% CV Acc, 5 Verified Credentials).
  - Quick action CTA buttons & direct links.
- **💼 Career Roadmap & Experience Screen**:
  - Interactive timeline showing **Loyalty Automation Pvt Ltd** (AI & Web Development Intern) and **CADS VIT Chennai** (Research Intern with NIOT polymetallic nodule segmentation, ICOE 2025 presentation).
  - Academic credentials for **VIT Chennai** (B.Tech ECM, CGPA 8.85), Class 12 (92%), and Class 10 (97.8%).
- **🚀 Featured Projects Screen**:
  - Filterable by categories: **All Projects**, **Agentic AI & LLMs**, **CV & IoT**.
  - Detailed cards for **South Indian Nutrition Advisor**, **Multi-Agent Autonomous Code Generator**, and **Smart Elevator Automation Prototype**.
  - Implementation bullets, tech badges, and direct **GitHub Source Code** links.
- **🛠️ Tech Stack & Skills Screen**:
  - Categorized grid: Languages, Frontend, Backend & DB, AI & Data, Hardware.
  - Interactive tap on any technology to view practical use-case and project integration details.
- **📜 Verified Credentials Screen**:
  - Oracle Agentic AI Associate & 4 Anthropic Claude Certifications with direct **Verify Credential ↗** links.
- **✉ Contact & Communication Screen**:
  - One-tap email launcher with custom in-app composer.
  - Direct links to GitHub and LinkedIn profiles.
  - Interactive Resume quick-view modal.
  - Toast feedback for quick actions.

## 🚀 How to Run the Mobile App

### Prerequisites
Make sure you have Node.js installed.

### 1. Start the Expo Development Server
Navigate into the `mobile` directory:
```bash
cd mobile
npx expo start
```

### 2. View on Your Phone (Android / iOS)
1. Install the **Expo Go** app from Google Play Store or Apple App Store.
2. Scan the QR code displayed in the terminal:
   - **Android**: Scan with the Expo Go app.
   - **iOS**: Scan with the default Camera app.

### 3. View in Android Emulator or iOS Simulator
- Press `a` in the terminal to open the Android Emulator.
- Press `i` in the terminal to open the iOS Simulator (macOS only).

### 4. View in Web Browser (Instant Preview)
- Press `w` in the terminal, or run:
```bash
npx expo start --web
```
This lets you preview and interact with the mobile app interface directly inside your web browser.
